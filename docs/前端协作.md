## 微吼 JSSDK 参考（做观看/播放器时必看）

契约侧总入口仍在 `../zhibo-shared/docs/API约定.md`（`/api/watch/{id}/sdk`）与决策 D24。前端改播放器、互动、底栏时，优先对照下面官方文档 + 本机 demo，不要凭记忆猜 API。

### Apifox（web 观播 SDK）

| 用途 | 链接 |
|------|------|
| 接入必读（版本 / 签名 / init） | https://vhall.apifox.cn/dev/sdk/jssdk/quick-start |
| 对接示例（初始化、自动播放、弹幕、清晰度、断点续播等） | https://vhall.apifox.cn/dev/sdk/jssdk/demo |
| 观看直播（`player` 模块 API：play/pause/清晰度/音量/弹幕…） | https://vhall.apifox.cn/dev/sdk/jssdk/live |
| 全局事件（`moduleReady` / `playerReady` / `vhallplay_*` / `live_over`…） | https://vhall.apifox.cn/dev/sdk/jssdk/events |
| 全局错误码 | https://vhall.apifox.cn/dev/sdk/jssdk/error-code |

互动工具（聊天/点赞/礼物/公告等）仍以 saas-doc 为准，见 shared `API约定.md`。观看端聊天字段（`chatServer.state.chatList` / get-list / `vhall_get_live_history_chat_msg` 三套形态、角色枚举）以 shared [`微吼对接.md`](../zhibo-shared/docs/微吼对接.md) **§6.2** 为准。

`player` 模块常用（直播底栏自建时）：`play` / `pause` / `canPlayDefinitions` / `setPlayerDefinition`；弹幕用 `openBarrage` / `closeBarrage`（业务弹幕走聊天发送）。点播才有倍速、seek、时长等。文档另有 `setMute`（静音自动播放设计）/`getVolume`，**自建底栏不用**。

**音量（自建底栏，2026-10-09）**：自建底栏音量只走 media（`#player video` / `audio` / `#player-vhall-video` 经 `findPlayerMedia()`）：滑条与静音钮只读写 `HTMLMediaElement.volume` / `muted`，同步 reactive `player.volume` / `player.muted`。SDK `setMute` / `getVolume` **不用于**滑条/静音钮（`getVolume` 易陈旧导致弹回中间/顶；`setMute` 易抛错或把 `media.volume` 拉成 1）。官方 demo 仅有静音开关无连续滑条，本站滑条以 media 为准。

#### Demo Player 目录（能学什么）

目录只有 3 个文件：`Index.vue`（壳）+ `PlayerSetting.vue`（竖屏设置面板）+ `PlayerSettingIcon.vue`（入口图标）。关键做法：

1. **容器**：`#videoContainer` 给 SDK `videoContent`；结束态拆掉节点销毁播放器。
2. **就绪**：听全局 `playerReady`，再 `setTimeout(50)` 后动 DOM（等控制条插完）；竖屏 **remove** `.vh-player-controller` / `.vh-player-record-control`；横屏保留原生条，Teleport 弹幕设置图标进 `.vh-player-right`。
3. **大播放钮**：竖屏 + `!isPlaying` 时居中出；点 `playerServer.play()`，并藏 `.vh-player-cover-mask`。播态跟 `playerServer.state.isPlaying`（demo 会把 `state` 包成 reactive）。
4. **竖屏自建设置**：清晰度/静音/倍速全走 **未文档化** `playerServer.*`；弹幕高级设置用 `loadCustomDanmakuSettingPopup()` 挂到自建 `#danmakuSettingContainer`。
5. **Main 侧**：`playerConfig.useCustomControl: false`——demo **不是**文档式「全量自定义控制 API」，而是竖屏拆掉原生条 + 自建面板 / 横屏改造原生条。

对本站：藏条用 `hiddneControl` **并** CSS/JS 永久藏 `.vh-player-controller`（见下「本站现状」）、大播放/底栏自建、清晰度走文档 `player.*`、音量用 media——路径已对齐且更稳。不要为抄 demo 去绑 `playerServer`；可学的是「`playerReady` 后再动控制条 DOM」「竖屏彻底拆原生条 vs 横屏改造」「弹幕设置用 SDK 面板挂载点」。

说明：文档公开 API 多在 `sdk.player.*`；demo 竖屏自建面板还用了内部的 `playerServer.*`（质量列表对象形态与 `canPlayDefinitions` 字符串码不同）。本站优先走文档 `player` API；只有文档没有、demo 才有的能力再评估 `playerServer`。

### 本站现状（对照用）

- 已用 SDK class `hiddneControl` 藏默认控制条（见 `VhallWatchAdapter`）。
- **自建底栏时必须永久隐藏 `.vh-player-controller` / `.vh-player-record-control`**，不能只靠叠盖：`hiddneControl` 只作用在 `.vhallPlayer-container` / shadow，**不覆盖**原生底栏节点；暂停卸掉 `PlayerToolbar` 后原生条会露出来。本站：`PlayerStage` `:deep` CSS `display:none !important` + adapter 在 MutationObserver 里再刷一次 inline hide。
- **底栏已完全自建**：`PlayerToolbar.vue` + `usePlayerControls`（播放/暂停、清晰度 `canPlayDefinitions`/`setPlayerDefinition`、音量 **仅 media**、弹幕/礼物/点赞/分享/全屏）。不再 Teleport / 依赖 `.vh-player-controller`。
