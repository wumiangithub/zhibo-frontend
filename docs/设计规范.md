# 设计规范（admin-web）

主题与视觉 token 以本文件为准；实现落在 `admin-web/src/styles/theme.css`。

## 主题切换

- 在 `<html>` 上设置 `data-theme`：
  - `default`：当前默认蓝（钱坤云）
  - 后续可加 `green` 等（`theme.css` 里已有注释示例）
- 业务代码**禁止写死品牌色十六进制**，统一用 CSS 变量。
- Element Plus 主色已映射到 `--el-color-primary*`，跟主题同步（官方 [CSS 变量主题](https://element-plus.org/zh-CN/guide/theming.html)，用 `color-mix` 派生 light/dark，不要写组件 class 覆盖）。
- 全量引入 `element-plus/dist/index.css`，`ElementPlusResolver({ importStyle: false })`，避免按需样式晚加载把主色冲回默认蓝。

```html
<html data-theme="default">
```

切换示例（后续可做设置页）：

```ts
document.documentElement.setAttribute("data-theme", "green");
```

## 用法

**scoped CSS：**

```css
.btn {
  color: var(--color-primary);
  background: var(--color-primary-bg);
}
```

**UnoCSS 原子类（任意值）：**

```html
<button class="bg-[var(--color-primary)] text-white hover:bg-[var(--color-primary-hover)]">
  保存
</button>
```

**SVG 图标跟主题色：** `fill`/`stroke` 用 `currentColor`，父级设 `color: var(--color-primary)`。

## 模块分区（新建直播页）

| 大模块 | 内容 |
|--------|------|
| 基本信息 | 模式、观看端样式、超低延迟、虚拟形象、名称、简介、时间、封面/暖场/宣传封面、详情、角色、回放、归属人、手机预览 |

## 样式文件约定

| 文件 | 放什么 |
|------|--------|
| `src/styles/theme.css` | **只放**主题 token（颜色变量、`data-theme`、Element Plus 主色映射） |
| `src/styles/*.css`（按需新建，如 `date-picker.css`） | 组件库覆盖、局部全局样式 |
| `*.vue` 的 `<style scoped>` | 该组件自己的布局与样式 |

组件覆盖类样式**不要**写进 `theme.css`。新建后在 `main.ts` 按需 `import`。

## 变更

改 token 或增主题：改 `theme.css`，并更新本表。不要在业务组件里散落新的品牌色硬编码。
