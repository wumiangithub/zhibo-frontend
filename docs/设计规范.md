# 设计规范（admin-web）

主题与视觉 token 以本文件为准；实现落在 `admin-web/src/styles/theme.css`。

## 主题切换

- 在 `<html>` 上设置 `data-theme`：
  - `default`：当前默认蓝（钱坤云）
  - 后续可加 `green` 等（`theme.css` 里已有注释示例）
- 业务代码**禁止写死品牌色十六进制**，统一用 CSS 变量。
- Element Plus 主色已映射到 `--el-color-primary*`，跟主题同步（官方 [CSS 变量主题](https://element-plus.org/zh-CN/guide/theming.html)，用 `color-mix` 派生 light/dark，不要写组件 class 覆盖）。
- 全量引入 `element-plus/dist/index.css`，`ElementPlusResolver({ importStyle: false })`，避免按需样式晚加载把主色冲回默认蓝。

```html
<html data-theme="default">
```

切换示例（后续可做设置页）：

```ts
document.documentElement.setAttribute("data-theme", "green");
```

## 用法

**scoped CSS：**

```css
.btn {
  color: var(--color-primary);
  background: var(--color-primary-bg);
}
```

**UnoCSS 原子类（任意值）：**

```html
<button class="bg-[var(--color-primary)] text-white hover:bg-[var(--color-primary-hover)]">
  保存
</button>
```

**SVG 图标跟主题色：** `fill`/`stroke` 用 `currentColor`，父级设 `color: var(--color-primary)`。

## 样式文件约定

| 文件 | 放什么 |
|------|--------|
| `src/styles/theme.css` | **只放**主题 token（颜色变量、`data-theme`、Element Plus 主色映射） |
| `src/styles/*.css`（按需新建，如 `date-picker.css`） | 组件库覆盖、局部全局样式 |
| `*.vue` 的 `<style scoped>` | 该组件自己的布局与样式 |

组件覆盖类样式**不要**写进 `theme.css`。新建后在 `main.ts` 按需 `import`。

## 变更

改 token 或增主题：改 `theme.css`，并更新本表。不要在业务组件里散落新的品牌色硬编码。

# live-web（观众观看主题）

实现：`live-web/src/styles/theme.css`（`main.ts` 已引入）。前缀 `--lw-`，与 admin 的 `--color-*` 隔离。

## 范围（先做这些，其它页面先不要）

| 纳入 | 不纳入 |
|------|--------|
| 观看直播 `WatchView`（含预告 / 直播中 / 结束态） | 首页、中控台壳层、课程页 |
| 观看回放 `WatchReplayView` | 登录等其它 live-web 页 |
| 上述页内的 `PreviewScreen` / `EndedScreen` / 聊天侧栏 / 播放器控件 | 在未挂 `lw-theme` 的树上写 `var(--lw-*)` |

中控台若复用预告/结束/播放器组件，只在**播放器那一块**包 `lw-theme`，不要给整页中控台换肤。

## 主题挂载

根节点：

```html
<div class="lw-theme" :data-lw-theme="theme">…</div>
```

- 默认 **`light`（白天）**；`dark` 为夜间
- 切换：`useWatchTheme`（`localStorage` key=`lw-watch-theme`）+ 播放器工具栏日/夜图标
- `UiBottomSheet` 会 `Teleport` 到 `body`，弹层根上也挂 `lw-theme` 并跟同一 `theme`，否则变量传不进去
- 纳入范围内禁止写死品牌色 / 面板底色，统一 `var(--lw-*)`；播放器舞台仍黑底

## 用法

UnoCSS 任意值：

```html
<div class="bg-[var(--lw-bg-panel)] text-[var(--lw-text-primary)] border-[var(--lw-border)]">
  <button class="border-b-2 border-[var(--lw-color-primary)]">聊天</button>
</div>
```

scoped CSS：`color: var(--lw-color-primary);`

**分工**：品牌橙只用于购买 / 进度条；发送、Tab 选中、主持人角标、提问勾选用 `--lw-color-primary`；主持人昵称用 `--lw-text-primary`；播放器清晰度·倍速选中用浅色字；「直播中 / 错误」用 live / danger，不要再用满屏 Tailwind `red-*`。
